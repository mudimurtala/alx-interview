# 0x0A. Prime Game

## Description

Maria and Ben are playing a competitive game involving prime numbers. Given a set of consecutive integers starting from 1 up to and including `n`, the players take turns selecting a prime number from the set and removing that number and its multiples from the set. The player who cannot make a move loses the game. 

This project requires the implementation of an optimal strategy to determine the winner of multiple rounds, assuming both Maria and Ben play optimally. 

Key concepts used include prime numbers, game theory, and algorithm optimization. The challenge is to identify the winner across multiple rounds of the game.
